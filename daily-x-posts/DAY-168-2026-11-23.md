## Post 3 — Problem/Solution Thread Starter

WAPDA-specific VFD traps nobody tells you about:

1. Single-phasing destroys motors — ensure phase-loss protection is built-in
2. Capacitor bank resonance — NEVER put cap bank on VFD input bus without de-tuning reactor
3. 48°C ambient in June — derate 1%/°C above 40°C or use IP55 + cooling
4. DG set switching — add 5% input line reactor for generator compatibility
5. Poor neutral-earth bonding — install TN-S system before commissioning
