### Reply Thread 1 — MCB Maximum Zs Table

Reply to primary:

Zs limits for 0.4s disconnection (230V, Type C MCB):
• 10A → 2.76Ω
• 16A → 1.73Ω
• 32A → 0.86Ω
• 63A → 0.44Ω

Long run with 1.5mm² wiring? Add an RCD — it protects where Zs is too high for MCB alone.

---

### Reply Thread 2 — RCD Trip Test (IEC 61008)

Reply to primary:

Pakistan socket circuits now require 30mA RCDs (LESCO 2024 update).

How to test: apply IΔn (30mA) → must trip in ≤300ms ✅
Apply 5×IΔn (150mA) → must trip in ≤40ms ✅

S-type (time-delayed) RCDs are for main incoming only — never in socket circuits.

### Reply Thread 3 — IR Test at 500V (common mistakes)

Reply to primary:

IR test fails on whole installation but passes per circuit?

Almost always: SPD / neon indicators / thermostats left connected. They're rated 230V — 500V Megger destroys them AND gives false low IR.

Disconnect every electronic accessory before testing. Retest per circuit individually.
