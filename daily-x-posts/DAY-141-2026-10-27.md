**Primary Post:**
Pakistan machinery PNP vs NPN sensor wiring mistake costs you 2 hours of commissioning every time.

Most Pakistan PLCs have NPN-sink inputs → buy PNP sensors.

But 40% of engineers wire it backwards, get zero signal, then blame the sensor.

Here's how to never get it wrong: 🧵

---

**Thread 1:**
PNP sensor = output connects to +24V when active.

Current flows FROM the sensor INTO the PLC input card.

PLC input card sinks the current to 0V.

Most Siemens S7, Delta DVP, Mitsubishi FX in Pakistan = NPN-sink inputs = BUY PNP sensors. ✅

---

**Thread 2:**
How to check your PLC card BEFORE ordering sensors:

PLC datasheet says:
- "Current sinking input" → buy PNP sensor ✅
- "Current sourcing input" → buy NPN sensor ✅

Check this ONCE, save 2 hours per commissioning job.

Never guess by brand name.

---

**Thread 3:**
3 sensor types Pakistani engineers confuse:

1. Inductive = detects METAL only (not plastic, not wood)
2. Capacitive = detects ANYTHING with dielectric higher than air
3. Photoelectric = detects anything that blocks/reflects light

Order wrong type = zero output on live machine. Simple check before ordering.
