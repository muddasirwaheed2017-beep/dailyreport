### Post 2 (Thread — The 3 RCCB Types Pakistan Solar Installers Must Know)

🧵 3 RCCB types. Pakistan solar installers get this wrong constantly.

**Type AC** ← what most Pakistan DB boards have
✅ Detects pure sine wave faults
❌ Cannot detect inverter leakage current
❌ Can fail SILENTLY on solar circuits (core saturation = doesn't trip when needed)

---

**Type A** ← what your solar DB board needs
✅ Detects sine wave faults
✅ Detects pulsating DC (inverter leakage)
✅ Has harmonic filtering (WAPDA feeder THD 8-18% causes nuisance tripping in Type AC)

Price: Rs 2,800–12,000 depending on rating

---

**Type B** ← for hybrid inverters with LFP battery
✅ All of the above
✅ Detects smooth DC leakage from battery bus

If your hybrid inverter has 48V LFP battery: Type B mandatory per IEC 62040-1.
Price: Rs 12,000–42,000

### Post 3 (Fact Thread — WAPDA Harmonic Problem)

Pakistan-specific RCCB problem nobody talks about:

WAPDA feeder THD: 8–18% (IEC limit = 5%)

3rd harmonic (150 Hz) current couples through solar panel frame capacitance into the earth conductor.

Type AC RCCB reads this as a fault → nuisance trip.

Peak nuisance trips: 14:00–17:00 PKT (solar peak + industrial VFD peak on same feeder)

Solution: Replace Type AC → Type A. Done.

### Post 4 (EV Charger Angle)

EV charger owners in Pakistan: your RCCB type matters.

Mode 2 charger (3.7 kW wall socket) → Type A RCCB required
Mode 3 charger (7.4–22 kW wallbox) → Type A RCCB required  
DC fast charger (25–150 kW) → Type B RCCB required

Type AC = not compliant with WLTP-2025 EV infrastructure standards.

BYD/MG warranties can be voided by wrong RCCB type.

### Post 5 (NEPRA Angle)

NEPRA net metering inspection checklist now includes RCCB type.

LESCO requirement: Type A minimum for solar ≤25 kWp. Type designation must be visible on enclosure without opening.

K-Electric requirement: Type AC explicitly prohibited for any inverter circuit.

Using wrong RCCB type = net metering application rejected.
