## Post

3 SCADA security mistakes Pakistani factories make — and what they cost.

I've visited dozens of industrial facilities across Faisalabad, Karachi, and Lahore over the past three years. The same three mistakes appear every time.

---

**Mistake 1: Default credentials on SCADA servers and OPC-UA servers**

Every major SCADA platform ships with a default admin account. Most Pakistani factory installations never change it.

An OPC-UA server running with default credentials and no network segmentation means any device on the factory LAN — including the accountant's Windows laptop browsing the internet — can read every sensor value and write to every PLC output.

IEC 62443 SL-1 baseline: change all default passwords. It takes 20 minutes.

---

**Mistake 2: USB drives as the "air gap bridge"**

Factories that physically isolate their OT network from the internet (correctly) often create a worse vulnerability: technicians carry USB drives between the internet-connected office PC and the isolated SCADA workstation to transfer PLC programs and recipe files.

USB-borne malware is the documented primary delivery vector for TRITON, BlackEnergy, and Industroyer ICS malware variants.

The fix: a dedicated file-transfer PC in a DMZ zone — the USB drive plugs into the DMZ PC, which scans the file and transfers it via controlled share to the SCADA server. No direct USB access to the OT zone.

---

**Mistake 3: Contractor remote access with flat network**

Third-party PLC and SCADA contractors in Pakistan almost universally use TeamViewer or AnyDesk to connect directly to the SCADA server or industrial PC. That SCADA server sits on the same flat network as every PLC in the plant.

One compromised contractor account — at the contractor's end, not yours — gives full PLC write access from anywhere on earth.

The fix: contractor access via a dedicated jump server in the DMZ, with per-session credentials, session recording, and network access scoped to only the specific IP addresses the contractor needs. Cost: PKR 0 additional hardware if your SCADA server is already segmented; one day of configuration.

---

**For export-oriented manufacturers:**

EU and US buyers are increasingly requiring IEC 62443 compliance evidence as part of supplier qualification. Textile exporters, pharmaceutical CMOs, and food processors supplying European retail chains are already receiving audit questionnaires that include ICS/SCADA security questions.

The cost of IEC 62443 SL-1 to SL-2 compliance for a mid-size Pakistani factory: PKR 250,000–500,000 in tools and audit fees. The cost of losing an EU buyer contract over a failed cybersecurity audit: substantially more.
